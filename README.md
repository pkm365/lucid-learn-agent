# 澄思学堂 · 亲手写 / 改一个 Agent —— 配套练习仓库

这是澄思学堂课程 **《亲手写一个 Agent》《亲手改一个 Agent》** 的配套练习仓库。
课程正文在 👉 **https://learn.pkm365.com**

课程用一份真实的开源 agent 框架 **pi**（MIT · https://github.com/earendil-works/pi）当教材——**不搭积木、不讲空概念，跟着一份能跑的真代码，一块块看懂、还能亲手改**。
这个仓库放的是：**每一集你要用 / 改的练习文件**，以及**怎么把 pi 跑起来**的说明。作者本人也不是程序员，是边学边做的。

## 怎么开始

1. 先读 **[SETUP.md](./SETUP.md)**，把 pi 跑起来（含几个新手必踩的坑）。
2. 按课程进度，进对应文件夹拿练习文件。

## 目录（对应课程章节）

| 文件夹 | 对应课程 | 里面有什么 |
| --- | --- | --- |
| [`改造实录-todo/`](./改造实录-todo/) | 《改造实录①：官方 Todo 崩了，我改一行修好》+ 逐行精讲 ①~④ | `my-todo.ts`（修复版扩展）+ 怎么跑 + 延伸练习 |

> 更多章节的练习文件，随课程更新陆续补充。
