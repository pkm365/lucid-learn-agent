# 澄思学堂 · 亲手写 / 改一个 Agent —— 配套练习仓库

这是澄思学堂课程 **《亲手写一个 Agent》《亲手改一个 Agent》** 的配套练习仓库。
课程正文在 👉 **https://learn.pkm365.com**

课程用一份真实的开源 agent 框架 **pi**（MIT · https://github.com/earendil-works/pi）当教材——**不搭积木、不讲空概念，跟着一份能跑的真代码，一块块看懂、还能亲手改**。
这个仓库放的是：**每一集你要用 / 改的练习文件**，以及**怎么把 pi 跑起来**的说明。作者本人也不是程序员，是边学边做的。

## 怎么开始

1. 先读 **[SETUP.md](./SETUP.md)**，把 pi 跑起来（含几个新手必踩的坑）。
2. 按课程进度，进对应文件夹拿练习文件。

## 目录：按「课程 / 章」组织，和网站一一对应

想找某一节的练习文件？照课程页的路径进来就行——**哪门课 → 哪一章**：

```
亲手改一个Agent/                 ← 课程
└── 改造实录-Todo扩展/           ← 章（对应站上「改造实录 · 亲手改一个 Todo 扩展」）
    ├── my-todo.ts               ← 练习文件（修复版扩展）
    └── README.md                ← 怎么跑 + 延伸练习
```

| 课程 | 章 | 练习文件 |
| --- | --- | --- |
| 亲手改一个 Agent | [改造实录-Todo扩展](./亲手改一个Agent/改造实录-Todo扩展/) | `my-todo.ts` |
| 亲手写一个 Agent | （练习文件随课程更新陆续补充） | — |

> 以后每做一集，练习文件就放进「对应课程 / 对应章」的文件夹，结构和网站保持一致——你在站上看到哪一章，就能在这里对着路径找到它的文件。
